# Sample MRI for upload

`BRATS_457.nii.gz` is a four-channel NIfTI brain MRI from the Medical Segmentation Decathlon `Task01_BrainTumour` dataset. Its shape is `240 × 240 × 155 × 4`, and its compressed size is 9,893,368 bytes. Upload this file to NeuroHeist's scan analysis form.

`BRATS_457_3D.nii.gz` is a derived single-channel 3D NIfTI made from channel 0 of the same scan, preserving its affine. Use it to test 3D uploads. The source attribution and CC BY-SA 4.0 license below also apply to this derived file.

Source: `Task01_BrainTumour/imagesTr/BRATS_457.nii.gz` in the [Medical Segmentation Decathlon archive](https://msd-for-monai.s3.us-west-2.amazonaws.com/Task01_BrainTumour.tar). The dataset is described at [medicaldecathlon.com](https://medicaldecathlon.com/) and is available under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The file is included here unchanged.

Citation: Antonelli et al., [The Medical Segmentation Decathlon](https://doi.org/10.1038/s41467-022-30695-9), *Nature Communications* 13, 4128 (2022).
